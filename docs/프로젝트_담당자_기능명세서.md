# 프로젝트 담당자 및 권한 기능 명세서 v0.1

## 1. 담당자 구성

- 한 프로젝트에는 여러 명의 담당자를 지정할 수 있다.
- 프로젝트 생성·편집 화면은 전체 사용자 목록을 체크박스로 표시한다.
- 생성 화면에서는 현재 로그인 사용자를 기본 선택한다.
- 저장할 때는 담당자를 한 명 이상 선택해야 한다.
- 기존 프로젝트에는 마이그레이션 시 프로젝트 생성자를 최초 담당자로 지정한다.

## 2. 권한

| 기능 | 프로젝트 담당자 | 그 외 로그인 사용자 |
|---|---:|---:|
| 프로젝트·오류·댓글 조회 | 가능 | 가능 |
| 프로젝트 생성 | 가능 | 가능 |
| 프로젝트 편집·보관 | 가능 | 불가 |
| 오류 상세 댓글 작성 | 가능 | 불가 |
| 오류 등록 | 가능 | 가능 |
| 기존 오류의 본문·상태·심각도·우선순위·담당자 수정 | 가능 | 오류 등록자 또는 현재 오류 담당자인 경우 가능 |
| 향후 +A 기능 | 같은 담당자 판정 사용 예정 | 불가 예정 |

화면에서 사용할 수 없는 버튼이나 댓글 입력 폼을 숨기며, 직접 요청을 보내더라도 서버가 동일한 권한을 검사한다.

## 3. 화면 표시

- 좌측 프로젝트 목록은 프로젝트명, 미종료 오류 수, 프로젝트 담당자 이름 순서로 세 줄을 표시한다.
- 담당자가 여러 명이면 표시 이름을 쉼표로 구분한다.
- 프로젝트 생성·편집 팝업에서 사용자 여러 명을 체크할 수 있다.
