# 검색 기능 명세서 v0.1

## 프로젝트 검색

- 메인 화면 상단의 프로젝트 생성 버튼 왼쪽에 검색창을 표시한다.
- 검색어를 입력할 때마다 대소문자 구분 없이 프로젝트명에 포함되는 항목만 즉시 표시한다.
- 일치하는 프로젝트가 없는 상태 그룹은 숨기고, 전체 결과가 없으면 안내 문구를 표시한다.
- 검색어를 지우면 기존 상태 그룹과 프로젝트를 다시 표시하며 그룹의 접힘 상태는 유지한다.

## 오류 검색

- 오류 목록의 정렬 버튼 왼쪽에 검색창을 표시한다.
- 현재 선택한 프로젝트와 현재 오류 상태 탭의 목록을 입력할 때마다 즉시 필터링한다.
- 제목, 오류 위치와 URL, 오류 설명, 재현 절차, 기대 결과, 실제 결과, 테스트 버전과 환경, 수정 제안을 검색한다.
- 검색 결과에 맞춰 총 건수를 갱신하고 결과가 없으면 안내 문구를 표시한다.
