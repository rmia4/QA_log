# 오류 등록 화면 명세서 v0.1

- 대상 화면: 오류 등록 (담당: 본인)
- 참고 문서: `writing-block.md`(DB 스키마), `docs/오류상세_화면명세서.md`(같은 우측 영역을 공유)

## 1. 진입 경로

오류 목록(우측 영역) 상단의 "오류 등록" 버튼 클릭 → 좌측 프로젝트 목록은 유지된 채 우측 영역이 등록 폼으로 전환.
저장하면 방금 만든 오류의 **상세 화면으로 이동**한다. "취소"를 누르면 검색·필터가 유지된 오류 목록으로 돌아간다.

## 2. 화면 구성

상세 화면과 같은 우측 영역을 쓰지만, 아직 존재하지 않는 오류라 배지·이력·댓글 영역은 없다.

| 순서 | 항목 | 입력 위젯 | 필수 |
|---|---|---|---|
| — | 현재 프로젝트 | 텍스트 표시(수정 불가, 좌측에서 선택된 값 자동 반영) | — |
| 1 | 제목 | text input | 선택 |
| 2 | 발생 위치 | text input | 선택 |
| 3 | URL 주소 | text input (`type=url`) | 선택 |
| 4 | 재현 순서 | textarea, 한 줄에 한 단계씩 입력 안내 문구 표시 | 선택 |
| 5 | 기대 결과 | textarea | 선택 |
| 6 | 실제 결과 | textarea | 선택 |
| 7 | 테스트 버전 | text input | 선택 |
| 8 | 테스트 환경 | textarea(짧게) | 선택 |
| 9 | 심각도 | select (미지정/낮음/보통/높음/치명적, 기본값 미지정) | 선택 |
| 10 | 우선순위 | select (미지정/낮음/보통/높음/긴급, 기본값 미지정) | 선택 |
| 11 | 개선 방향 | textarea | 선택 |
| 12 | 첨부파일 | 드래그앤드롭 + 파일 선택, 다중 선택, 선택 즉시 미리보기 목록(제출 전 개별 삭제 가능) | 선택 |
| 13 | 처리 담당자 | select (팀원 목록 + "미지정") | 선택 |

**필수 입력 항목 없음** — 전 항목 비워둔 채로도 저장 가능(자동값만으로 저장, writing-block.md 확정 사항).

## 3. 위젯 세부 규칙

- **재현 순서**: 사용자가 한 줄에 한 단계씩 입력하면, 상세 화면에서는 줄바꿈 기준으로 나눠 번호 목록(`1. 2. 3. ...`)으로 렌더링한다. 입력 힌트 문구: "한 줄에 하나씩 입력하세요"
- **첨부파일**: 스크린샷용 이미지 형식만 허용(첫 버전 기준, 기능명세서 3.3 참고). 허용 확장자 밖 파일은 선택 즉시 클라이언트에서 걸러내고 안내 문구 표시
- **심각도/우선순위**: 드롭다운 기본 선택값은 "미지정" — 사용자가 굳이 고르지 않아도 자동으로 `unspecified`로 저장됨
- **처리 담당자**: 목록은 동기 쪽 사용자 API(`GET /users` 또는 동등 기능)에서 `id`+`display_name`만 받아 구성 — 이 화면은 사용자 테이블 구조에 의존하지 않음

## 4. 버튼

| 버튼 | 동작 |
|---|---|
| 등록 | 저장 요청 전송, 성공 시 상세 화면으로 이동 |
| 취소 | 확인 없이 즉시 오류 목록으로 복귀(검색·필터 유지), 입력한 내용은 저장되지 않음 |

첫 버전에는 "임시저장(초안)" 기능을 두지 않는다 — 등록 폼을 벗어나면 입력 내용은 사라진다.

## 5. 참고

- 등록 폼과 오류 상세의 "본문 수정" 폼은 필드 구성이 동일하다 — 컴포넌트를 공유해서 만들 수 있다(구현 시 참고)
- 색상·타이포 톤은 `docs/오류상세_화면명세서.md` 4절과 동일 기준을 따른다
