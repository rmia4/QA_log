# 오류 목록 기능 명세서 v0.1

## 표시 항목

오류 목록에는 번호, 오류 제목, 상태, 심각도, 우선순위, 담당자, 등록일, 수정일을 표시한다.

우선순위 표시값은 다음과 같다.

| 저장값 | 화면 표시 |
|---|---|
| `unspecified` | 미지정 |
| `low` | 낮음 |
| `normal` | 보통 |
| `high` | 높음 |
| `urgent` | 긴급 |

## 정렬

- 정렬 버튼은 오류 목록 우측 상단에 심각도, 우선순위, 등록일, 수정일 순서로 표시한다.
- 기본 정렬은 심각도 내림차순이다.
- 현재 선택된 정렬 버튼을 다시 누르면 오름차순과 내림차순을 전환한다.
- 우선순위 내림차순은 긴급, 높음, 보통, 낮음, 미지정 순서다.
- 우선순위 오름차순은 이 순서의 반대다.
- 같은 정렬값을 가진 오류는 최신 등록 항목부터 표시한다.

## 목록 전환

- 진행 중·종료됨 탭을 누르면 전체 페이지를 이동하지 않고 오류 목록 영역만 갱신한다.
- 심각도·우선순위·등록일·수정일 정렬 버튼도 오류 목록 영역만 갱신한다.
- 현재 프로젝트, 프로젝트 목록, 프로젝트 검색어는 그대로 유지한다.
- 오류 검색어가 입력된 상태에서는 새 목록에도 같은 검색어를 즉시 적용한다.
- 주소에는 선택한 탭과 정렬 조건을 반영하며, 브라우저 뒤로가기·앞으로가기로 이전 목록 상태를 복원한다.

## 페이지네이션

- 오류 목록은 한 페이지에 최대 10건을 표시한다.
- 10건을 초과하면 목록 아래에 이전·페이지 번호·다음 버튼을 표시한다.
- 진행 중·종료됨 탭 또는 정렬 기준을 변경하면 해당 결과의 1페이지부터 표시한다.
- 오류 검색은 현재 페이지에 한정하지 않고 선택된 상태의 전체 오류를 대상으로 하며, 검색 결과를 다시 10건씩 나눈다.
- 현재 페이지는 주소의 `page` 값에 반영하고 뒤로가기·앞으로가기로 복원한다.


## 인라인 수정

- 오류 등록자, 현재 오류 담당자, 해당 프로젝트 담당자는 목록에서 상태, 심각도, 우선순위, 담당자를 바로 변경할 수 있다.
- 권한이 있는 행은 기존 배지와 같은 모양의 `select`로 표시하고, 권한이 없는 행은 읽기 전용 배지로 표시한다.
- 담당자가 미지정인 오류는 위 권한이 없는 사용자에게도 담당자 선택창을 표시하되, 자기 자신에게 할당하는 선택지만 제공한다.
- 심각도와 우선순위는 `미지정`을 포함한 전체 코드값을 선택할 수 있으며, 담당자도 `미지정`으로 변경할 수 있다.
- 선택 즉시 form-urlencoded POST 요청을 보내며 페이지 전체를 새로고침하지 않는다.
- 요청 중에는 선택창을 잠그고, 실패하면 이전 값과 색상으로 되돌린 뒤 원인을 안내한다.
- 성공 응답의 최신 `updatedAt`으로 행의 낙관적 잠금 기준과 수정일 표시를 갱신한다. 이어서 다른 필드를 수정할 때 이 값을 사용한다.
- 저장 직후에는 현재 행을 재정렬하거나 다른 상태 탭으로 옮기지 않는다. 새로고침, 탭 전환, 정렬 버튼 사용 시 DB 값을 기준으로 목록을 다시 구성한다.
- 오류 목록 HTML이 교체된 뒤에도 동작하도록 `document`의 `change` 이벤트 위임을 사용한다.

| Method | Path | 설명 |
|---|---|---|
| POST | `/api/issues/{id}/status` | 상태 인라인 변경 |
| POST | `/api/issues/{id}/severity` | 심각도 인라인 변경 |
| POST | `/api/issues/{id}/priority` | 우선순위 인라인 변경 |
| POST | `/api/issues/{id}/assignee` | 담당자 인라인 변경 |

네 요청은 조회 시점의 `expectedUpdatedAt`을 함께 보내며, 충돌은 409, 권한 없음은 403, 허용되지 않은 값은 400으로 응답한다.
